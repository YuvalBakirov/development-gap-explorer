## מה נבדק בפועל

המערכת הורידה את עמודי ה־API, שמרה אותם כתמונות raw נפרדות, סיננה אגרגטים,
בנתה טבלת CSV רחבה לפי מדינה ושנה, ושמרה דוח איכות ו־manifest לשחזור הריצה.
המשתמש הריץ את הפקודה המקומית `python etl.py` בסביבת VS Code עם גישת אינטרנט.
