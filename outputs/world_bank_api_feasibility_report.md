# דוח היתכנות World Bank Indicators API

## מסקנה

ה־API מתאים למטלה ולמוצר Development Gap Explorer, עם הסתייגות מרכזית:
אינדיקטור ההרשמה לחינוך תיכוני דל משמעותית מהאחרים ולכן צריך להישאר אופציונלי.
ארבעת מדדי הליבה — תוצר לנפש במחירים קבועים, אבטלה, תוחלת חיים ואוכלוסייה —
מספקים בסיס טוב ל־ETL ולניתוח. אין צורך להחליף מקור נתונים בשלב זה.

הבדיקה בוצעה בפועל מול World Bank API עבור השנים 2010-2024. כל המספרים בדוח
מחושבים מהתגובות שנמשכו, ולא מהערכה מוקדמת.

## ישויות ומדינות

ה־country endpoint החזיר 295 רשומות מטא־דאטה. לפי המטא־דאטה הנוכחי:

- 217 הן מדינות או כלכלות עם אזור גאוגרפי ממשי.
- 78 הן ישויות אגרגטיביות, כגון World, קבוצות הכנסה ואזורים.
- אגרגטים מזוהים באמצעות `region.id = "NA"` ו־`region.value = "Aggregates"`.
- ארצות הברית (`USA`) נבדקה כמדינה ו־World (`WLD`) נבדק כאגרגט.

האגרגטים לא נכללו בחישובי הכיסוי או ב־joins של המדינות.

## היתכנות join

מפתח ה־join שנבדק הוא `countryiso3code + year`.

- 2,730 מתוך 3,255 שורות, 83.87%, מלאות בכל ארבעת מדדי הליבה.
- הוספת מדד צמיחת התוצר מורידה את הכיסוי בשתי שורות בלבד: 2,728, שהם 83.81%.
- דרישה שכל ששת המדדים יהיו מלאים משאירה 1,942 שורות בלבד, 59.66%.
- ל־186 מדינות יש לפחות שנת ליבה מלאה אחת.
- ל־173 מדינות יש את כל ארבעת מדדי הליבה בכל 15 השנים.

לכן אין לבצע inner join קשיח על כל ששת המדדים. נכון יותר לבנות טבלת
country-year רחבה באמצעות left joins, לשמור דגלי חסר, ולחשב השוואות רק כאשר
המדדים הדרושים זמינים. מדד החינוך יוצג כשכבה אופציונלית ולא כתנאי לזכאות.

## מטא־דאטה והגדרות

כל ששת הקודים קיימים במקור World Development Indicators, source ID 2.

- `NY.GDP.PCAP.KD`: תוצר לנפש בדולרי 2015 קבועים, מותאם לשינויי מחירים.
- `NY.GDP.PCAP.KD.ZG`: שינוי שנתי באחוזים בסדרת התוצר לנפש במחירי 2015 קבועים.
- `SL.UEM.TOTL.ZS`: שיעור כוח העבודה ללא עבודה, זמין לעבודה ומחפש עבודה;
  הסדרה היא modeled ILO estimate.
- `SP.DYN.LE00.IN`: מספר השנים שיילוד צפוי לחיות אם דפוסי התמותה במועד לידתו
  יישארו קבועים לאורך חייו. זהו מדד תקופתי, לא תחזית שהמוצר שלנו מייצר.
- `SP.POP.TOTL`: אוכלוסיית אמצע שנה לפי הגדרת de facto.
- `SE.SEC.ENRR`: יחס הרשמה גולמי, ולכן יכול לחרוג מ־100% ואינו שקול לשיעור
  התלמידים בגיל הרשמי בלבד.

תגובות הנתונים דיווחו `lastupdated = 2026-07-13`. בכל התצפיות הלא־ריקות של
המדינות השדה `obs_status` היה ריק; אף תצפית לא סומנה ב־API כ־forecast.

## pagination ואיכות טכנית

כדי לבדוק pagination במכוון נעשה שימוש ב־`per_page=1000`.

- country metadata הוחזר בעמוד אחד עם 295 רשומות.
- כל אינדיקטור החזיר 3,975 שורות בארבעה עמודים: 1,000, 1,000, 1,000 ו־975.
- סכום הרשומות בכל העמודים תאם בדיוק ל־`total` שדווח בתגובה.
- לא נמצאו מפתחות כפולים של מדינה–שנה באף אינדיקטור.
- לא נמצאו קודי ISO3 לא ממופים לאחר סינון האגרגטים.
- אין צורך ב־API key.

## החלטה מומלצת לפני המימוש המלא

להמשיך עם World Bank API ועם השנים 2010-2024. ארבעת מדדי הליבה יהיו תוצר
לנפש, אבטלה, תוחלת חיים ואוכלוסייה. צמיחת התוצר תישמר כמדד משלים וכבדיקת
עקביות מול השינוי המחושב מהסדרה הקבועה. ההרשמה לחינוך תיכוני תישאר אופציונלית
ותוצג רק כאשר יש מספיק נתונים, בלי להפיל מדינות מהניתוח המרכזי.

המוצר יישאר תיאורי: הוא יזהה פערים ודפוסים הראויים למחקר נוסף, ולא יסיק
סיבתיות, לא יפיק תחזיות ולא ייתן המלצות השקעה.
